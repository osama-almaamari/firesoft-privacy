FireSoftSQLBackup - Privacy Policy

Last updated: 29 October 2026

What the application is

FireSoftSQLBackup is a desktop program that runs on the user's own Windows computer. It creates backups of the user's databases and stores them in a local folder or in the user's own Google Drive.

Google user data

When the user signs in with Google, the program requests access to Google Drive only to create, upload, list and delete the backup files that the user chose to store there. The access token is saved encrypted on the user's own computer. It is never sent to the developer or to any third party.

What we collect

We do not collect, receive, store, sell or share any personal data, Google user data or backup content. Everything stays between the user's computer and the user's own Google account.

Limited use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The user can remove the program's access at any time from myaccount.google.com/permissions.
